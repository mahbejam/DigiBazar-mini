## Processing notes

- Downloaded from Unsplash CDN (`images.unsplash.com`)
- Center-cropped to square, resized to 1000 × 1000
- JPEG quality adjusted so each file is under 500 KB
- Imported into the WordPress Media Library and set as each product’s featured image
